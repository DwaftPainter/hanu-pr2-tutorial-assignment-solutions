# HANU PR2 Tutorial Assignment Solutions (Java)

HANU PR2 Tutorial Assignment Solutions is a Java practice repository containing weekly programming exercises, official references, and sample implementations for Programming 2 (PR2). This project helps students review Java basics, object-oriented programming, file I/O, recursion, collections, and simple data management tasks.

## About This Repository

This repository provides **PR2 tutorial assignment solutions** organized by week.  
You can use it to:
- Compare your own solutions with reference-style code
- Practice Java problem-solving and coding patterns
- Review common university-level Java assignments

## Topics Covered

Key Java topics in these tutorial solutions include:
- Java syntax and control flow
- Arrays, sorting, and matrix operations
- Classes, objects, and inheritance
- Interfaces and polymorphism
- Exception handling
- File input/output
- Recursion
- Collections and basic DAO patterns

## Repository Structure

Source code is organized under:

- `src/Week01` to `src/Week11`: Weekly tutorial exercises and solutions
- `src/InputFile`: Input files used by some assignments

## How to Use

1. Clone or download this repository.
2. Open it in your Java IDE (IntelliJ IDEA, Eclipse, or VS Code).
3. Navigate to the target week folder in `src/`.
4. Run each Java class independently to study behavior and output.

## Who This Is For

- HANU students studying Programming 2 (PR2)
- Beginners practicing Java through structured weekly exercises
- Learners preparing for Java programming tests and assignments
